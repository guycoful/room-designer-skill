# מעצב הבית

מנתח תמונת חדר, מציע שלושה כיווני עיצוב ופרומפט להדמיה.

הסוכן הזה התחיל כ-Gem בג'מיני של גיא כהן, והועבר לסקיל כשגוגל הודיעה שה-Gems עוברים ל-Skills. ההוראות הועתקו מילה במילה.

## איך משתמשים

1. [הורדה ישירה של SKILL.md](https://raw.githubusercontent.com/guycoful/room-designer-skill/main/SKILL.md). הקובץ נפתח כטקסט.
2. שומרים אותו בשם SKILL.md בתיקייה בשם `room-designer`.
3. מעלים לכלי שיש לכם. ב-Claude: Customize, Skills, Create skill, Upload a skill. ב-Gemini Spark: Skills, Upload.

מדריך ההמרה המלא, כולל איפה מריצים סקיל עם המנוי שכבר יש: https://claude.ai/artifact/UKg2bkoJDCzECgs2C7zSen
